# Third-party data and model notices

BREST source code and the bundled synthetic demo do not include third-party
model weights, pathology images, or patient expression matrices.

## H0-mini

BREST preprocessing can use `bioptimus/H0-mini` to produce 1,536-dimensional
cell features. The checkpoint is not included. Obtain it from its official
distribution and review the upstream license before use or redistribution.
The BREST demo contains synthetic arrays with the same feature width, not
H0-mini outputs.

## CellViT

The full preprocessing path uses CellViT cell centroids. CellViT code and
weights are not included. Follow the upstream CellViT repository's citation and
license requirements.

## HEST

Full-scale spatial experiments use samples distributed through HEST. HEST data
is not included in this repository. Download it from the official source and
follow its attribution and CC BY-NC-SA 4.0 terms. The bundled demo is generated
from scratch and is not a HEST subset.

## TCGA

Full-scale bulk covariance estimates use TCGA expression cohorts. TCGA files
and patient identifiers are not included. Users are responsible for complying
with the applicable GDC/TCGA data-use terms.

## Demo artifact

`demo/demo_data/brest_toy_coad.npz` contains no third-party numerical data. It is
generated by `demo/build_demo_data.py` and released under CC0-1.0. Gene symbols
are used only as identifiers.
