# BREST demo data

`brest_toy_coad.npz` is a deterministic synthetic cohort used only to exercise
the public BREST workflow. It contains four 8-by-8 toy slides, six cells per
spot, 1,536-dimensional cell features, 64 COAD-panel gene labels, and a
256-sample synthetic bulk reference.

The values are generated by `../build_demo_data.py`; no patient data, pathology
images, HEST-derived arrays, H0-mini weights, or model checkpoints are included.
The numeric artifact is released under CC0-1.0. Gene symbols are identifiers,
not biological claims about the synthetic values.

The fixed split is:

- `train_A`, `train_B`: model fitting
- `validation`: checkpoint selection by Gene PCC
- `test`: final metrics and plots

The notebook masks 12 of 64 genes to demonstrate Direct, BLUP-true, and
BLUP-pred completion. Full evaluation masks 100 genes and uses Visium
leave-one-slide-out or Xenium five-fold evaluation without subsampling.

Rebuild and verify the artifact:

```bash
python demo/build_demo_data.py
python demo/validate_demo.py
```
